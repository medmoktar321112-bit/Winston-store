# WINSTON STORE Android App
تطبيق Android أولي متعدد اللغات مبني على واجهة Winston Store الحالية.
اللغات: العربية، Français، English.
الاسم: WINSTON STORE.
الدفع: واجهة اختيار Bankily/Sedad فقط في هذه النسخة؛ الربط الحقيقي يحتاج حسابات التاجر وبيانات API الرسمية.
لبناء APK، افتح المشروع في Android Studio أو استخدم بيئة بناء Android متوافقة.
